# مواصفات وخطة تنفيذ مشروع: إضافة تواصل بلغة الإشارة العربية الموحدة على WhatsApp Web

> **توجيه لأداة الذكاء الاصطناعي (AI Context):**  
> هذا الملف يحتوي على المواصفات الكاملة لمشروع تخرج (مستوى متوسط، مستقر، وقابل للمناقشة). المطلوب منك عند قراءة هذا الملف أن تفهم معمارية المشروع، قيود الميزانية الصفرية، الاعتماد على APIs وأدوات مجانية بدون بناء موديلات AI من الصفر، وخطة تقسيم العمل على 6 أفراد في مرحلتين، ثم تبدأ فوراً في مساعدة الفريق في كتابة الكود أو بناء المكونات المطلوبة عند الطلب.

---

## 1. نظرة عامة على المشروع (Project Overview)

* **نوع المشروع:** مشروع تخرج جامعي (Graduation Project).
* **المنصة المستهدفة:** إضافة لمتصفح Google Chrome (Chrome Extension - Manifest V3) تعمل بواجهة منبثقة (**Popup UI**).
* **نطاق العمل الحالي:** موقع **WhatsApp Web** فقط (مع اشتراط تثبيت الإضافة لدى المرسل والمستقبل).
* **اللغات المدعومة:** اللغة العربية الفصحى (Modern Standard Arabic) ↔ لغة الإشارة العربية الموحدة (Unified Arabic Sign Language).
* **الميزانية:** صفر (الاعتماد الكامل على أدوات مفتوحة المصدر، Browser APIs، وFree-Tier APIs).
* **منهجية الذكاء الاصطناعي:** استخدام APIs ومكتبات جاهزة دون بناء أو تدريب نماذج عميقة من الصفر (مع تدريب تصنيف خفيف جداً داخل المتصفح فقط لجزء قراءة الكاميرا).

## 2. اتجاهات الترجمة الستة والـ APIs المقترحة

| # | الاتجاه | هل يحتاج تدريب؟ | الأداة / الـ API المجاني المقترح | آلية العمل |
| :--- | :--- | :--- | :--- | :--- |
| 1 | **صوت ← نص** | لا | `Web Speech API` (`SpeechRecognition` في Chrome) أو Free Whisper API | التقاط صوت المستخدم بالعربية الفصحى (`ar-SA` / `ar-EG`) وتحويله لنص فوري. |
| 2 | **نص ← صوت** | لا | `Web Speech API` (`window.speechSynthesis`) | نطق النص العربي الفصحي بصوت واضح داخل المتصفح مجاناً. |
| 3 | **نص ← لغة إشارة** | لا | Free LLM API (اختياري لتبسيط الجملة لـ Gloss) + قاموس JSON | مطابقة الكلمات العربية بقاموس إشارات (فيديو/GIF/صور) وعرضها بالترتيب. |
| 4 | **صوت ← لغة إشارة** | لا | دمج (1) + (3) | تحويل الصوت لنص فصيح، ثم مطابقة الكلمات وعرضها بلغة الإشارة. |
| 5 | **لغة إشارة (كاميرا) ← نص** | تدريب خفيف جداً | `MediaPipe Hands` (JS/WASM) + مصنّف `TensorFlow.js` أو KNN | استخراج نقاط اليد (21 Landmarks) ثم تصنيفها لحروف أو كلمات (20–50 إشارة). |
| 6 | **لغة إشارة (كاميرا) ← صوت** | نفس (5) | دمج (5) + (2) | تحويل الإشارة الملتقطة بالكاميرا إلى نص عربي ثم نطقه عبر `speechSynthesis`. |

## 3. شكل عرض لغة الإشارة ومصادر البيانات المجانية (Datasets)

بما أن الميزانية صفر والمشروع يعتمد على السرعة والبساطة بدون تعقيد الـ 3D Rigging من الصفر، فإن **أنسب شكل لعرض لغة الإشارة** هو **مقاطع فيديو قصيرة أو صور متحركة (GIFs / WebM) أو عرض تسلسل صور** من قاموس إشارات موحد، مربوط بملف `dictionary.json` يربط كل كلمة عربية أو حرف بالملف الخاص بها.

### مصادر و Datasets مفتوحة المصدر للغة الإشارة العربية:
1. **قاموس لغة الإشارة العربية (فيديوهات/إشارات مرجعية):**
   * [القاموس الإشاري العربي للصم (menasy.com)](https://menasy.com/) — قاموس مرئي شامل لمفردات لغة الإشارة العربية.
   * [القاموس الإشاري العربي للصم - المنظمة العربية لمترجمي لغة الإشارة](https://selaa.org/ar/node/204)
2. **قواعد بيانات للتعرف على الإشارة بالذكاء الاصطناعي (لجزء الكاميرا):**
   * [ArabSign Dataset](https://hamzah-luqman.github.io/ArabSign/) — قاعدة بيانات للغة الإشارة العربية الموحدة (9,335 عينة تمثل 50 جملة).
   * [ArSL-31-Pilot (Zenodo)](https://zenodo.org/records/18363162) — بيانات إحداثيات نقاط اليد (MediaPipe Hand Landmarks) جاهزة للغة الإشارة العربية.
   * [ArASL / ArSL2018 Dataset](https://pmc.ncbi.nlm.nih.gov/articles/PMC6661066/) — قاعدة بيانات تضم 54,049 صورة لـ 32 حرفاً وإشارة عربية قياسية.
   * [AraSLP Datasets Directory (GitHub)](https://github.com/Hamzah-Luqman/AraSLP/blob/main/datasets.html) — فهرس يجمع أشهر قواعد بيانات لغة الإشارة العربية.
   * [Pose_SLR (GitHub)](https://github.com/snalyami/Pose_SLR) — مشروع مرجعي للتعرف على لغة الإشارة العربية باستخدام نقاط MediaPipe.

## 4. المعمارية التقنية وبروتوكول الرسائل على WhatsApp Web

### أ. مكونات الإضافة (Chrome Extension - Manifest V3)
1. **Popup UI (`popup.html` / `popup.js` أو React):**
   * واجهة منبثقة يختار منها المستخدم وضع الإرسال أو الاستقبال، يسجل الصوت، يفتح الكاميرا، أو يعرض ترجمة الإشارة.
2. **Content Script (`content.js`):**
   * يعمل داخل `https://web.whatsapp.com/*` لقراءة الرسائل الواردة في الشات المفتوح، وحقن الرسائل الصادرة في مربع الكتابة وإرسالها.
3. **Background Service Worker (`background.js`):**
   * ينسق الرسائل والحالة بين الـ Popup والـ Content Script ويدير استدعاءات الـ APIs الخارجية (إن وُجدت).

### ب. بروتوكول الرسائل السريع والخفيف (Lightweight Payload)
لأن الطرفين يملكان نفس الإضافة، لا يتم إرسال ملفات فيديو ثقيلة عبر واتساب، بل تُرسل **رسالة نصية مهيكلة وخفيفة** يلتقطها الـ Content Script عند الطرف الآخر ويعرضها فوراً:

```text
[ARSL|v1|type=SIGN|gloss=مرحبا كيف حالك] مرحبا، كيف حالك؟
```

* **الميزة:** سرعة فائقة في الإرسال، لا تستهلك مساحة، وتظل مقروءة كنص عادي حتى لو فُتحت المحادثة مؤقتاً من الهاتف، بينما تقوم الإضافة على Chrome بعرض الإشارة المرئية أو تشغيل الصوت تلقائياً عند المستقبل.

## 5. خطة تقسيم العمل على 6 أشخاص (على مرحلتين)

### المرحلة الأولى: بناء وحدات الترجمة الأساسية (عمل فردي متوازي — 6 وحدات مستقلة)
في هذه المرحلة، يبني كل فرد وحدة برمجية مستقلة (`ES Module` أو صفحة اختبار HTML/JS بسيطة) بمدخلات ومخرجات واضحة (`Input -> Output`) لتسهيل دمجها لاحقاً:

| العضو | الوحدة المسؤولة عنها | المدخل والمخرج المطلوب | الأدوات المقترحة |
| :--- | :--- | :--- | :--- |
| **عضو 1** | **تحويل الصوت إلى نص (Speech → Text)** | Input: ميكروفون ← Output: نص عربي فصيح (`string`) | `Web Speech API` (`webkitSpeechRecognition`) + معالجة الأخطاء |
| **عضو 2** | **تحويل النص إلى صوت (Text → Speech)** | Input: نص عربي (`string`) ← Output: نطق صوتي واضح | `Web Speech API` (`speechSynthesis`) + اختيار الصوت العربي |
| **عضو 3** | **تحويل النص إلى لغة إشارة (Text → Sign)** | Input: نص عربي ← Output: تسلسل فيديوهات/GIFs متتالية | مطابقة الكلمات + خوارزمية Fallback للحروف + `dictionary.json` |
| **عضو 4** | **تحويل الصوت إلى لغة إشارة (Speech → Sign)** | ربط مخرجات الصوت بمسار معالجة النص (Arabic-to-Gloss) وعرض الإشارة | Free LLM API (مثل Gemini Free Tier) لتبسيط الجملة + دمج وحدة 1 و3 |
| **عضو 5** | **تحويل لغة الإشارة إلى نص (Sign → Text)** | Input: بث كاميرا ← Output: الحرف أو الكلمة المكتشفة | `MediaPipe Hands` (JS) + مصنّف خفيف (`TensorFlow.js` / KNN) |
| **عضو 6** | **تحويل لغة الإشارة إلى صوت + القاموس** | Input: النص المكتشف من الكاميرا ← Output: صوت منطوق + تجهيز القاموس | دمج وحدة 5 و2 + تجميع وتنظيف 30–50 إشارة + الأبجدية في `dictionary.json` |

### المرحلة الثانية: دمج الإضافة والربط مع WhatsApp Web (عمل جماعي — الـ 6 أفراد)
بعد انتهاء المرحلة الأولى، يتعاون الـ 6 أفراد لتحويل الوحدات إلى إضافة Chrome متكاملة:

* **عضو 1 و 2 (واجهة المستخدم والـ Popup):** تصميم وبناء واجهة الـ Popup (أزرار التسجيل، الكاميرا، مشغل الإشارة، وإعدادات السرعة والصوت) وتجربة المستخدم (UX).
* **عضو 3 و 4 (الربط مع WhatsApp Web و Manifest V3):** كتابة `manifest.json` و`content.js` لالتقاط الرسائل الواردة بالبادئة `[ARSL|...]` وإرسال الرسائل الصادرة لمربع الدردشة في WhatsApp Web باستخدام `MutationObserver`.
* **عضو 5 (التنسيق وإدارة الحالة):** ربط الـ `background.js`، إدارة صلاحيات الميكروفون والكاميرا داخل الإضافة، وتنسيق تدفق البيانات بين الـ Popup وWhatsApp Web.
* **عضو 6 (الاختبار والتوثيق والمناقشة):** اختبار الإضافة من البداية للنهاية (E2E) بين حسابين مختلفين على جهازين، توثيق المشاكل وحلولها، وإعداد سيناريو العرض العملي وملف المناقشة للجنة.

## 6. هيكل المجلدات المقترح للمشروع (Project Structure)

```text
arsl-whatsapp-extension/
├── manifest.json              # إعدادات Chrome Extension (Manifest V3)
├── background.js              # Service Worker لإدارة الحالة
├── content/
│   └── whatsapp-bridge.js     # الحقن والقراءة من DOM الخاص بـ WhatsApp Web
├── popup/
│   ├── popup.html             # واجهة الإضافة المنبثقة
│   ├── popup.css              # تنسيق الواجهة (دعم RTL للعربية)

│   ├── textToSpeech.js        # (عضو 2)
│   ├── textToSign.js          # (عضو 3)
│   ├── speechToSign.js        # (عضو 4)

    ├── dictionary.json        # ربط الكلمات والحروف بملفات الإشارة
    └── signs/                 # ملفات الفيديو/GIFs/الصور للغة الإشارة الموحدة
```
